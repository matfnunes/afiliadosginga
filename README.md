# Affiliate Content Dashboard

Dashboard para auditoria contratual de entregas de afiliados.

## Funcionalidades

- Controle de entregas por afiliado
- Auditoria contratual (status: Pendente, Entregue, Auditado, Reprovado)
- Filtros por plataforma, formato e status
- Histórico de postagens com link do conteúdo
- Suporte a múltiplas plataformas e formatos

## Tecnologias

- [Next.js 14](https://nextjs.org/)
- [React 18](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- Deploy: [Vercel](https://vercel.com/)

## Como rodar localmente

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Deploy na Vercel

```bash
npm install -g vercel
vercel
```


# Affiliate Content Dashboard

## Descrição
Dashboard para auditoria contratual de entregas de afiliados.

## Funcionalidades
- Controle de entregas
- Auditoria contratual
- Histórico de postagens
- Gestão operacional de afiliados
- Controle por plataforma
- Controle por formato de conteúdo

---

# Estrutura do Projeto

```bash
app/
 └── page.js
```

---

# Como rodar localmente

## Instalar dependências

```bash
npm install
```

## Rodar projeto

```bash
npm run dev
```

Abrir:

```bash
http://localhost:3000
```

---

# Deploy na Vercel

## Instalar Vercel CLI

```bash
npm install -g vercel
```

## Fazer deploy

```bash
vercel
```
